## 1. Classifier Decision Rule (verbatim logic, `src/signal_assessment/classifier.py:51-79`)

`positive_count` = number of the 5 criteria with `passed=True`.

1. `positive_count >= 3` OR (`positive_count >= 2` AND `persistence.passed`) → **Signal**, confidence `min(0.5 + 0.1×positive_count, 0.95)`
2. `positive_count >= 2` (persistence failed) → **Weak Signal**, confidence `min(0.3 + 0.1×positive_count, 0.6)`
3. `positive_count == 1` OR `|z| >= 2.0` → **Watch**, confidence `min(0.2 + 0.1×positive_count, 0.4)` → observed `0.3`
4. `positive_count == 0` AND `|z| < 0.5` → **Ignore**
5. otherwise (0 positive, `|z| >= 0.5`) → **Noise**

## 2. Collector Filter Rule (`src/evidence_collection/collector.py:88-104`)

- `Noise` and `Ignore` → discarded (never become Evidence).
- `Signal`, `Weak Signal`, `Watch` → become Evidence.
- Evidence `composite_weight = obs.confidence × regime_weight`; regime_weight observed `0.6` → every Watch item: `0.3 × 0.6 = 0.18`.
